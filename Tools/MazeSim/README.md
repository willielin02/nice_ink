# MazeSim — 醉夢迷宮離線設計儀器（2026-07-14~15）

與 UE `FDreamMazeGen` **同構的 python 移植**（FRandomStream 逐位元；v3.5 拓樸已同步：
五門對稱殼／無整圈環廊／禁入殼）。改 UE 生成器時**必須同步這裡**，否則圖與模擬全是舊拓樸。
（逐位元同種子同圖在 v3.4 驗證過；v3.5 改版後未重驗種子級一致，結構斷言 15 迷宮全過。）

依賴：PIL（臉部管線 venv 有：`nice_ink_face_pipeline/venv/Scripts/python.exe`）。

## render_maze_map.py — 上帝視角全圖

```
python render_maze_map.py <seed> <cup 0-2> <輸出png>
```

畫出迷宮＋隱形陷阱實際位置＋技能點＋出口＋避開陷阱的最短安全路（灰紫線；遊戲中全部不顯示）。
字幕帶繞行比與正解決策點。

## sim_playtime.py — 通關時間分布（蒙地卡羅）

```
python sim_playtime.py [種子數=120] [每種子局數=3]
```

有記憶的探索玩家模型：偏外探索＋完美記憶走過格；死亡=回原點+9s 懲罰鏈；
旋轉後以 p_keep 機率保住心智地圖（三檔原型 0.2/0.5/0.8 夾人為因素上下界）。
2026-07-14 發現：反貪婪迷宮的探索係數≈理想 8-9 倍（舊 2-4 倍係數作廢）；
環 7/8/9 純探索中位 63-94s＝尺寸單獨超回合預算（環數降檔待 user 裁決）。

## sim_gamelength.py — 整場局數分布（一局＝畫＋猜）

```
python sim_gamelength.py [場數=20000]
```

回合引擎：猜對換人歸零、猜錯 +1、一任三杯終局；p=判讀三數模型
（e_t 硬證據率×0.9＋f 被餌率×0.02＋裸猜 b=1/(N-1)×畫風累積）。
2026-07-14 發現：傑作總數守恆律成立（27-42 幅）；終局壓力=(1−p)³ 立方消失
＝無限猜對鏈尾巴的量化形狀（判讀天花板是控制變數，朋友房最暴露）。
SPEC 錨點：首任即出局 陌生人 1/3、朋友 1/8 → p≈0.31/0.50。

全部是 bot 模型估計——真值以 playtest 三數（e_t/f/b）為準；這些工具的用途是
改規則前先看形狀，不是代替真人。
